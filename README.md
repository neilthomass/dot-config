# dotfiles

My macOS coding setup.

```bash
git clone https://github.com/neilthomass/dotfiles ~/dotfiles
cd ~/dotfiles
./install.sh
```

## Tools

- [Starship](https://starship.rs) — prompt
- [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions) — history suggestions
- [zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting) — command coloring
- [thefuck](https://github.com/nvbn/thefuck) — command correction
- [Ghostty](https://ghostty.org) — terminal
- [tmux](https://github.com/tmux/tmux) — multiplexer
- [Zed](https://zed.dev) — primary editor
- [VS Code](https://code.visualstudio.com) — secondary editor
- [Neovim](https://neovim.io) — in-terminal editing
- [git](https://git-scm.com) — version control
- [gh](https://cli.github.com) — GitHub CLI
- [lazygit](https://github.com/jesseduffield/lazygit) — git TUI
- [git-lfs](https://git-lfs.com/) — large file storage
- [gitleaks](https://github.com/gitleaks/gitleaks) — secret scanning
- [mise](https://mise.jdx.dev) — version manager
- [node](https://nodejs.org) + [pnpm](https://pnpm.io) — JS runtime
- [go](https://go.dev) — Go toolchain
- [rustup](https://rustup.rs) — Rust toolchain
- [python@3.11](https://www.python.org) — Python runtime
- [cmake](https://cmake.org) — C/C++ build system
- [ccache](https://ccache.dev) — compile cache
- [protobuf](https://protobuf.dev) — protoc
- [AeroSpace](https://github.com/nikitabobko/AeroSpace) — tiling WM
- [Karabiner-Elements](https://karabiner-elements.pqrs.org) — key remapping
- [Stats](https://github.com/exelban/stats) — menu-bar monitor
